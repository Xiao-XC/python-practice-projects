## 📋 Planned Projects

### 1. Data Cleaning Script (Beginner)
- **What:** Take a messy CSV (missing values, inconsistent formatting) and clean it with pandas.
- **Skills needed:** Python basics + intro pandas
- **Resume angle:** "Automated data cleaning for [X]-row dataset, handling missing values and formatting inconsistencies with pandas."

### 2. Exploratory Data Analysis (EDA) Project
- **What:** Pick a public dataset (Kaggle, data.gov) and answer 3-5 real questions about it with charts.
- **Skills needed:** pandas, matplotlib/seaborn
- **Resume angle:** "Analyzed [dataset] to uncover [insight], visualizing trends using pandas and seaborn."

### 3. API/Web Scraping Data Collector
- **What:** Pull live data from an API (weather, stocks, sports, Reddit) and store it in a structured format.
- **Skills needed:** `requests`, basic JSON handling
- **Resume angle:** "Built a Python script to collect and structure real-time [X] data via public API."

### 4. Basic Machine Learning Model
- **What:** Train a simple classifier or regressor (e.g., predict house prices, classify spam) using scikit-learn.
- **Skills needed:** pandas + scikit-learn basics
- **Resume angle:** "Trained a [model type] achieving [X]% accuracy on [dataset], using scikit-learn."

### 5. End-to-End Capstone Project
- **What:** Combine everything — collect data, clean it, analyze it, visualize it, maybe deploy a small dashboard.
- **Skills needed:** everything above
- **Resume angle:** "Developed an end-to-end data pipeline from [source] to [insight/dashboard]."
