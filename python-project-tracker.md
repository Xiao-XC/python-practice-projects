## 🧱 Skill Roadmap (in order)
1. Python fundamentals (in progress — freeCodeCamp)
2. Working with files & data (csv/json)
3. `pandas` — data cleaning & analysis
4. `matplotlib` / `seaborn` — visualization
5. Basic APIs & web scraping (`requests`, `BeautifulSoup`)
6. `scikit-learn` — basic ML (classification/regression)
7. (Stretch) Deploying a small app (`Streamlit`)

---

## 📋 Planned Projects

### 1. Data Cleaning Script (Beginner)
- **What:** Take a messy CSV (missing values, inconsistent formatting) and clean it with pandas.
- **Skills needed:** Python basics + intro pandas
- **Resume angle:** "Automated data cleaning for [X]-row dataset, handling missing values and formatting inconsistencies with pandas."

### 2. Exploratory Data Analysis (EDA) Project
- **What:** Pick a public dataset (Kaggle, data.gov) and answer 3-5 real questions about it with charts.
- **Skills needed:** pandas, matplotlib/seaborn
- **Resume angle:** "Analyzed [dataset] to uncover [insight], visualizing trends using pandas and seaborn."

### 3. API/Web Scraping Data Collector
- **What:** Pull live data from an API (weather, stocks, sports, Reddit) and store it in a structured format.
- **Skills needed:** `requests`, basic JSON handling
- **Resume angle:** "Built a Python script to collect and structure real-time [X] data via public API."

### 4. Basic Machine Learning Model
- **What:** Train a simple classifier or regressor (e.g., predict house prices, classify spam) using scikit-learn.
- **Skills needed:** pandas + scikit-learn basics
- **Resume angle:** "Trained a [model type] achieving [X]% accuracy on [dataset], using scikit-learn."

### 5. End-to-End Capstone Project
- **What:** Combine everything — collect data, clean it, analyze it, visualize it, maybe deploy a small dashboard.
- **Skills needed:** everything above
- **Resume angle:** "Developed an end-to-end data pipeline from [source] to [insight/dashboard]."

**Project name:** ISBN Validator (debugging lab, freeCodeCamp)
**Date:** Sept 2026
**What it does:** Validates ISBN-10 and ISBN-13 codes by calculating and comparing check digits, with error handling for malformed input (wrong length, non-numeric length, non-comma-separated input, invalid characters).
**Tools/libraries used:** Core Python (string slicing/indexing, list comprehensions, try/except error handling)
**What I learned:** Debugging someone else's broken code instead of writing from scratch — spotting a `TypeError` from wrong argument count in `len()`, tracing an off-by-one slicing bug by manually counting string indices, and using `try`/`except ValueError` to catch bad input (e.g. `int('-')`) instead of crashing.
**Resume bullet (final):** "Debugged and fixed a multi-error Python ISBN validation program, resolving indentation errors, off-by-one indexing bugs, and unhandled exceptions to pass all 20 test cases."

**Project name:** Planet Class (freeCodeCamp lab)
**Date:** Sept 2026
**What it does:** A `Planet` class with input validation (type + non-empty checks), an `orbit()` method, and a custom `__str__` method for clean object printing. Three instances created and demonstrated.
**Tools/libraries used:** Core Python (classes, `__init__`, `__str__`, `raise`/custom exceptions, `isinstance`)
**What I learned:** First object-oriented programming lab — classes, instance attributes, dunder methods (`__init__`, `__str__`). Learned the difference between `try`/`except` (catching errors Python raises on its own) vs `raise` (deliberately throwing an error yourself based on a condition you check). Also reinforced "validate first, assign second" as a general pattern, and chaining conditions with `or` instead of repeating near-identical `if` blocks.
**Resume bullet (final):** "Built a Python class with custom input validation and string representation methods, applying object-oriented principles including dunder methods and custom exception handling."
